一注册入口在哪

主窗口右上角点「注册」（开始试用或注册完成后，该入口显示为「关于」），即可打开注册 / 关于窗口。

窗口内分三个页签，并在底部提供一排通用入口：

  • 单台离线/在线激活：办理单机注册的两种方式都在这一页
  • 两台在线授权/升级：办理 2 台终身在线授权与授权升级
  • 购买须知/官方信息：购买、申请、反馈、客服、官网五个二维码
  • 窗口底部：查看价格、权益说明、注册方法三个入口
本窗口只负责「办理与激活」，不摆放说明书。价格在官网价格表查看， 权益与办理方法即《权益说明》与本文档，由窗口底部按钮一键打开。

二离线激活（单机注册）

适合不想联网、或想直接把申请码发给客服办理的用户。全程不需要登录账号。

  1. 在「单台离线/在线激活」页签点「复制申请信息」，申请码（本机设备身份）与联系方式会整串复制到剪贴板，供填单时直接粘贴。
  2. 某宝下单付款后，用手机扫「购买须知/官方信息」页的离线申请码，打开收集单填单：订单号 ＋ 邮箱 ＋ 本机设备身份（复制申请信息后直接粘贴）。
  3. 卖家核对订单后，授权码发送到你填写的邮箱。
  4. 回到「单台离线/在线激活」页签，把授权码粘贴到输入框，点「激活」。
申请码请复制后直接粘贴，不要手抄。它由本机硬件信息生成，换机器会变化； 先点「复制申请信息」把整串申请码放进剪贴板，手机填单时先发到自己的 微信（文件传输助手）再粘贴。手抄容易断行或改错字符，会导致签出的授权码在本机激活不通过。

激活成功后全部功能即时解锁，无需重启软件，状态显示为 单机已注册。

三在线激活（单机注册）

同样办单机注册，但免去扫码填单：某宝下单付款后直接在软件内提交订单号即可。

  1. 某宝下单付款，复制订单号（从某宝 App「我的订单」详情里复制）。
  2. 在「单台离线/在线激活」页签点「单台在线激活申请」，填入订单号与接收授权码的邮箱，提交。
  3. 卖家核对后，授权码自动发送到该邮箱。
  4. 在「两台在线授权/升级」页签用收码邮箱登录，登录成功后点「拉取授权 / 刷新设备」，自动完成激活。
提交时会一并把本机设备身份带上，卖家据此签出「在本机可直接激活」的授权码， 因此不需要再手工抄写申请码。
不想登录账号也可以：按邮件提示把授权码粘贴到「单台离线/在线激活」页签的 输入框，点「激活」，结果与自动激活完全一样。
断网时软件内提交不了：对话框会自动展开离线申请二维码与本机设备身份， 改用手机填单即可，两条通道最终都通过邮箱收码。

四两台在线授权（2 台终身）

适合要在两台电脑上使用、或需要换机的用户。以账号为中心，一次办理、多机可用。

  1. 在「两台在线授权/升级」页签用邮箱验证码登录（首次登录自动注册账号）。
  2. 登录后软件会自动登记本机并尝试拉取授权；已付款的也可先点「两台在线授权申请」提交订单号。
  3. 卖家核对订单后，回本页点「拉取授权 / 刷新设备」，授权即时生效，状态显示为 在线已授权，当场解锁全部功能（无需重启软件）。

更换电脑

  1. 新电脑安装软件，用同一账号登录。
  2. 点「设备管理（查看 / 解绑 / 换机）」，解绑旧电脑。
  3. 回本页点「拉取授权 / 刷新设备」，新机即可使用。
新设备绑定后 7 天内为绑定冷静期，期间不可自助解绑； 同一设备 90 天内限自助解绑 1 次。这是为了保障账号与设备不被他人随意转移。

五授权升级（老授权 → 现行 2 台终身）

已经办理过授权的用户，都可按自己的情况补差价升级到现行 2 台终身在线授权 权益（2 台、终身、可换机）。按当初办理的档位分两种情形，走的是同一个入口、同一套流程。

你的情况 升级目标 补差价
已购单机注册
（当年单台买断）		 现行 2 台终身在线授权 单台价与 2 台终身价的差额，金额以官网价格表公布为准
已购 2 台终身
（当年两台买断）		 现行 2 台终身在线授权 两台买断价与现行价的差额，金额以官网价格表公布为准

办理步骤（两种情形相同）

  1. 先到官网价格表核对当期补差价金额（两种情形的金额不同，见上表）。
  2. 在某宝下单付款补差价。
  3. 打开「两台在线授权/升级」页签，点「两台在线升级申请」，填写补差价订单号与邮箱并提交 （原购买订单号选填：只有原购买未关联到当前账号的历史订单才需填写）。
  4. 卖家核对后，后续流程与在线授权一致：用收码邮箱登录后点「拉取授权 / 刷新设备」，即完成激活。
已购 2 台终身（当年两台买断）的用户：不必另找入口，同样在 「两台在线授权/升级」页签点「两台在线升级申请」提交即可。升级后与现行 2 台终身在线授权完全一致 —— 设备管理、换机、后续版本免费升级全部可用。
升级时限：须在最后一台注册成功（激活）之日起 180 天（半年）内办理，逾期升级通道关闭。

六常见问题

换电脑后原来的授权还能用吗？

  • 单机注册：不能，授权码绑定原机硬件信息。新机需重新办理，或按「授权升级」升到在线授权获得可换机能力。
  • 在线授权：可以，新机登录同一账号、解绑旧机、拉取授权即可。

激活后需要重启软件吗？

不需要。授权在激活瞬间即时生效，受限入口即刻解锁。

重装系统要重新注册吗？

单机注册：授权码绑定本机硬件指纹（取自 CPU 序列号），重装系统、清理系统都不会改变指纹，授权照旧；只有更换 CPU 这类会改变指纹的部件才需重新办理。在线授权：用同一账号登录后点「拉取授权 / 刷新设备」即恢复。

点了「关于 / 注册」没有反应？

窗口是独立进程，可能已被其它窗口遮挡。同一时刻只允许打开一个注册 / 关于窗口，重复点击会把已有窗口拉到前台。若仍无反应，请重启软件再试。

离线能激活吗？

能。离线激活通道全程不需要联网，授权码验签在本机完成，之后离线也能正常使用。

软件里为什么看不到价格了？

价格统一在官网价格表公布，软件内只提供跳转入口。这样调整价格无需更新软件，也不会出现「软件与官网价格不一致」的情况。

试用到期后数据会丢吗？

不会。软件数据保存在本机用户目录，试用到期只是把专业版功能暂时置灰，注册后立即恢复。
