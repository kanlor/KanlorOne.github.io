KanlorOne MDinDocx — Word 中的 MD 插件

一、产品简介

KanlorOne MDinDocx（中文名：Word中的MD插件）是一款装在 Word / WPS 里的 Markdown 双向转换插件。说白了，它让 Markdown 文件和 Word 文档在同一条路上来回走：打开 .md 就变成一篇能正常编辑、带规范样式的 Word 文档；写完了点一下「另存为 MD」，又变回干净的 Markdown。

它对标 Writage，覆盖其全部核心功能，并且同时支持 Word 与 WPS 两端——这是它相对同类工具最大的不同。除此之外，它还覆盖了从 AI 网页粘贴内容、数学公式原生还原、引用文献生成、标题方案换装、格式模板库，到标题编号、标点转换、图片表格标准化这一整条文档整理链路。

插件以功能区标签页的形式嵌在 Word / WPS 顶部，打开宿主就能用，不需要另外开一个软件窗口。

最新更新（v0.3.3）：把一批常用的排版整理能力搬进插件——标题自动编号、WBS 与公文标题识别、中英标点互转、多余空格清理、无用样式清理、图片与表格标准化，同时重做了注册与授权体验。

二、核心特色

🤔 你是否遇到这些问题？
  • 从 ChatGPT 复制一段回答粘到 Word，代码块、公式、表格全糊成一坨纯文本？
  • 攒了一堆 .md 笔记要发给同事，对方只认 Word，手工重排太费劲？
  • 在 Word 里写好的东西要发到博客或代码仓库，手工改成 Markdown 格式几乎要重写一遍？
  • 文档里的公式在 Word 中是图片，既改不了也算不出来？
  • 参考文献格式要求按 APA / IEEE 排，一条条手改到眼花？
  • 拼来的文档带着一堆用不上的样式，想统一格式却怎么改都不动？
✅ KanlorOne MDinDocx 的核心优势
  • 双向往返：打开 .md 即渲染为可编辑 Word，另存为 .md 时标题、列表、表格、公式、脚注原样回去
  • AI 内容保格式粘贴：ChatGPT / Claude / Gemini 的内容一键粘贴，代码块、公式、表格、脚注不丢
  • 公式是真公式：$...$ / $$...$$ 转成 Word 原生方程，双击就能继续编辑
  • Word + WPS 双端支持：同一套插件，两种宿主都能装、都能用
  • 标题方案一键换装：内置「科技」「公文」两套档位，改的是样式定义，全文标题自动跟随
  • 格式模板库：把满意的一段格式命名存下来，跨文档、跨会话随时复用
  • 整理工具齐全：标题自动编号、标题识别、标点转换、空格清理、无用样式清理、图片与表格标准化
  • 即开即用：激活后功能区按钮立刻解锁，不用重启 Word / WPS

三、使用指南（8步搞定）

1
下载并安装：点下方「五、下载安装」里的下载按钮，从微云获取安装包。安装程序会自动把插件装到你的 Word 和 WPS，并建立 .md 文件的右键关联，不需要你手动配置任何东西。
2
彻底退出宿主：把正在运行的 Word、WPS 全部关掉（包括停留在后台的窗口），再重新打开。加载项只在宿主启动的那一刻装载，不重启是不会出现的。用 WPS 的同学请先装好 WPS 官方 VBA 支持包，否则页签能显示但按钮点不动。
3
找到功能区：重新打开 Word / WPS，顶部会出现「MDinDocx」标签页，里面的按钮按用途分成若干组：文件、粘贴、插入、样式、标题方案、编号识别、列表、格式、文本、清理整理、管理。
4
打开一篇 Markdown：点「打开 MD」选择 .md 文件（安装后也可以直接在资源管理器里右键 .md 文件选「用 MDinDocx 打开」）。文档立刻渲染成可编辑的 Word 文档，# / ## / ### 会变成「标题 1 / 2 / 3」，导航窗格和目录都能正常识别。
5
从 AI 网页搬内容：在 ChatGPT / Claude / Gemini 里复制回答，回到 Word 点「粘贴 AI 内容」，代码块、公式、表格、脚注按原来的结构落地，不用再手工收拾。想先看效果，可以先用「粘贴预览」。
6
修排版：缺编号就点「编号识别」组的「自动编号」，标题没样式就点「识别 WBS」或「识别公文」；格式想统一，用「标题方案」一键换装，或把满意的一段「存为模板」放进格式模板库；标点、空格、无用样式、图片表格尺寸，都在「文本」「清理整理」两组里。
7
转回 Markdown：点「另存为 MD」选择保存位置，得到 .md 文件和配套的 media/ 图片目录。如果只想把其中几段给别人，选中内容点「复制 MD」，Markdown 源码直接进剪贴板。
8
需要 PDF：点「导出 PDF」，在 Word 内以原生方式导出，排版和你在屏幕上看到的一致。
常用动线：打开 MD → 编辑/粘贴 → 标题方案或编号识别 → 格式模板库统一格式 → 另存为 MD 或导出 PDF。日常只用其中两三个按钮就够了，其余按钮留着备用。

四、功能详解

功能区里的按钮非常多，下面按用途分组说明。第一次用不必全看，遇到需要时回来查即可。

4.1 双向转换

按钮作用
打开 MD把 .md 文件渲染成可编辑的 Word 文档。标题映射为内置标题样式，列表、表格、引用、代码块、脚注、公式一并还原。
另存为 MD把当前文档转换回 Markdown，图片统一落到同目录的 media/ 文件夹。主标题 / 副标题会写成 Markdown 的标题元数据，不会在往返中丢掉。
导入文件夹整个目录的 .md 文件合并成一份 DOCX，适合把一堆零散笔记并成一本册子。
导出 PDF在 Word 内以原生方式导出 PDF。

4.2 粘贴与复制

  • 粘贴 MD：把剪贴板里的 Markdown 源码按格式插入到光标处。
  • 复制 MD：选中的内容转成 CommonMark 语法写回剪贴板；没有选区时按整篇处理。
  • 粘贴 AI 内容：专治从 ChatGPT / Claude / Gemini 复制的回答——代码块、公式、表格、脚注无损落地。
  • 粘贴预览：先看一眼剪贴板里 Markdown 排成什么样，确认了再插进文档。

4.3 标题与样式

分项作用
主标题 / 副标题一键设为文档主标题、副标题，对应 Word 内置样式；往返 Markdown 时写成 title / subtitle 元数据。
标题 1 ~ 标题 9把光标所在段落设成对应级别的大纲标题，也支持快捷键 Ctrl+1 ~ Ctrl+9。
正文 / 清除样式不管当前是什么样式，一律恢复为正文；「清除格式」还会顺带清掉直接格式。
标题方案内置「科技」与「公文」两套档位，一键把主标题、副标题、标题 1~9 全部换装。因为是改样式定义而不是逐段刷格式，全文已有标题会自动跟随，导航窗格与目录照常识别。也可以「自定义…」新建一套自己的方案，或点「方案详情」查看当前方案参数。
格式模板库「存为模板」把选中文字的格式命名保存（含中文字体、颜色、底纹、下划线、字符单位缩进等），跨文档、跨会话都能再调用；「模板库」里可以应用、重命名、删除。另有「复刻格式 / 应用格式」用于当次临时搬格式。

4.4 编号与标题识别

这一组是 v0.3.3 新加的，专门收拾「标题没编号」「标题没套样式」这两件麻烦事。

按钮作用
自动编号按大纲级别给标题排号：一级是 1、二级是 1.1，跳级时中间缺失的层级自动补 1。标题里原本已经有的旧编号会被就地改正，不会越编越乱。编号时只改编号那一小段文字，标题里的加粗、字体、颜色不会被压平。
取消编号去掉标题段落开头的编号文字，是「自动编号」的反向操作。
识别 WBS把以 1 / 1.1 / 1.2.3 开头的段落套用标题 1~9 级样式。
识别公文按公文层级识别并套用样式：一、 → 标题1，（一） → 标题2，1. → 标题3，（1） → 标题4。
标题体检只读统计各级标题的数量与其中带编号的数量，不改动文档。
不会认错的地方：数字点（3.14）、年份（2024 年）这类「看着像编号」的内容会被主动排除；以句号收尾或明显过长、更像正文的段落也不会被硬认成标题——宁可少认一行，也不把错误标题写进大纲。

4.5 列表与插入

  • 列表组：有序、无序、任务（复选框列表），以及「升高级别 / 降低级别」调整缩进层级。
  • 插入组：图片、链接、表格、脚注、公式，按 Markdown 的写法插入到你正在编辑的 Word 文档里，保持结构规范。

4.6 文本处理

按钮作用
清理文本全角转半角、去掉不可见字符、去掉首尾多余空格。有选区只处理选区，没有选区处理全文。圈号（①）和单位（㎏）这类中文文档里常见的字符不会被吞掉。
统一字体把选中内容（无选区则全文）的字体与字号统一。弹窗里选过的字体和字号会被记住，下次打开直接沿用。
冒号加粗把冒号（: / ：）前面的文字加粗，适合「定义：说明」这类成段文档；如果已经全加粗了，再点一下就取消。
段落间距统一行距与段前、段后间距。
删空段删除空段落。表格内的段落和文档最后一段会保留，有选区时只清理选区内。
时间戳在光标处插入当前日期时间。
文档统计统计字数、字符数、行数、页数、段落数与表格数。

4.7 清理整理

按钮作用
标点转中文半角标点转全角，中文引号按成对交替给出开 / 闭引号，... 与 …… 双向互转。数字点、网址、邮箱、文件路径和反引号里的内容会跳过，不会把 3.14 改成 3。14。
标点转英文全角标点转半角，《》、「」 这类中文专有标点保持原样。
多余空格段首缩进和 Tab 一律保留；英文单词之间的连续空格折叠成一个（保留间隔）；中文之间、中文与英文之间、行尾的空格整段删除。
无用样式删掉文档里没被用到的自定义样式，清理样式面板。删除前会先列出清单让你确认；正在使用中的样式，以及 Word / WPS 自带的样式一律受保护。
图片标准化浮动图片转为嵌入、按页面可用宽度等比缩放（只缩不放）、居中并清掉缩进、强制单倍行距（避免固定行高把图片截断）。表格里的图片会跳过，免得把单元格撑破。
表格标准化统一表格宽度、行高（按内容撑开的最小值）、中英文字体与字号、首行加粗与底色、首行跨页重复、单元格水平垂直居中，并套用内置的「网格型」表格样式。

4.8 设置与授权

  • 设置：转换相关的偏好项，包括 Markdown 输出风味、引用文献所用的 .bib 文件与 CSL 样式、代码块底纹等开关。
  • 许可：点一下查看当前授权状态（已注册 / 试用中 / 未授权），并即时刷新。
  • 注册 / 关于：打开注册窗口，内含「离线/在线激活」「在线授权/升级」「购买与联系」页签，以及软件版本、申请码、操作说明、检查更新入口。
  • 文件关联：安装后 .md / .markdown 文件可以直接右键「用 MDinDocx 打开」，渲染成可编辑文档。

4.9 引用文献（可选）

在设置中配置好 .bib 文献库与 CSL 样式后，就可以在文档里用 [@引用键] 的写法引用文献。转换时会按所选样式（APA、IEEE、MLA 等 9 种）自动生成规范的参考文献列表，不用手工排版。

五、下载安装

下载 Windows 64位（Word / WPS 加载项）
运行环境
  • 操作系统：Windows 64 位（提供 Win10+ 与 Win7 两个版本，功能完全一致，同一微云链接内按需选择）
  • 宿主程序：Microsoft Word 或 WPS Office，二者装其一即可
  • 用 WPS 的用户请先安装 WPS 官方 VBA 支持包，否则页签会出现但按钮没有反应
安装步骤
1
点上方下载按钮，从微云链接获取安装包
2
先关闭正在运行的 Word 与 WPS，避免安装时插件文件被占用
3
双击运行安装程序，按提示完成安装。程序会自动把插件部署到 Word 与 WPS，并建立 .md 文件的右键「用 MDinDocx 打开」关联
4
重新打开 Word / WPS，顶部功能区出现「MDinDocx」标签页即为安装成功
5
如果只看到页签、点按钮没反应，说明宿主缺少宏环境（多见于 WPS 个人版），装好 VBA 支持包后重启即可
试用说明

全功能试用，按设备计算，重装不重置。首次使用在注册窗口点「开始试用」即可，试用期内转换、粘贴、导入导出等全部功能开放，不需要做任何注册动作。

试用结束后，转换类功能需要注册解锁；编辑与排版类功能不受限制，可以继续使用。

注册与授权

离线注册：功能区「管理 → 注册 / 关于」或「许可」，复制申请码发给客服，收到授权码后粘贴激活。一码一机，校验过程不需要联网。

在线授权：在注册窗口「在线授权 / 升级」页签登录账号，由云端把设备与账号绑定并下发授权码。软件内可查看已绑定的设备列表、按规则自助解绑与换机。

激活即时生效：授权状态变化后功能区按钮会立刻变化，不需要重启 Word / WPS。

检查更新：注册窗口底部有「检查更新」按钮；发现新版本时只会在下次打开注册窗口时提示，不会在写作过程中弹窗打扰。

七、常见问题

问：装完了，功能区没有「MDinDocx」页签？

答：九成是宿主没重启——加载项只在 Word / WPS 启动的那一刻装载，请彻底退出（包括停留在后台的窗口）再打开。另一种情况是安装时 Word 正开着，插件文件被占用没能部署成功，重新运行一次安装程序即可。

问：WPS 里页签出现了，但按钮点了没反应？

答：这是 WPS 个人版默认不带宏引擎导致的——页签是界面，按钮要跑起来还需要宏环境。装上 WPS 官方 VBA 支持包后重启 WPS 就能恢复，插件本身没有问题。

问：试用是怎么算的？

答：全功能试用，按设备计算，重装不重置。首次使用点「开始试用」即可，期间转换、粘贴、导入导出等全部功能开放；试用结束后这些功能需要注册解锁，编辑与排版类功能不受限制，可以继续用。

问：公式转过去还能编辑吗？

答：能。Markdown 里的 $...$ 行内公式和 $$...$$ 块级公式会转成 Word 原生方程，双击就能继续编辑；另存为 Markdown 时再还原成 LaTeX 写法。

问：从 ChatGPT 复制的回答粘进来会乱吗？

答：用「粘贴 AI 内容」就不会，别用普通的 Ctrl+V。代码块、公式、表格、脚注都会按原来的结构落地，而不是糊成一段纯文本。想先确认效果，可以先用「粘贴预览」看一眼再插入。

问：.md 里的图片去哪了？

答：打开 .md 时图片按原路径载入；另存为 Markdown 时，文档里的图片会统一落到同目录的 media/ 文件夹，.md 中写的是相对路径引用，拷走整个文件夹就不会掉图。

问：「另存为 MD」会不会改坏我原来的 Word 文档？

答：不会。转换不会改动当前文档的身份与路径，只是另外产出一份 .md 文件，你手上的 Word 文档保持原样。

问：离线注册和在线授权该选哪个？

答：想免联网、不想登录账号，走离线注册：把申请码复制发给客服，拿到授权码粘贴激活，一码一机。需要多设备，或者想自己查看绑定设备、解绑换机，就走在线授权：登录账号后由云端下发授权码，设备管理在软件内自助完成。两条通道的授权效果一致，装好之后功能区按钮都会即时解锁。
