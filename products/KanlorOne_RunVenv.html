KanlorOne RunVenv — 虚拟环境启动器

一、产品简介

KanlorOne RunVenv（虚拟环境启动器）是一款 Python 脚本的运行与管理工具。简单来说，你把平时要敲命令才能跑起来的脚本交给它，之后选脚本、点运行、看结果，全程都在一个窗口里完成，不用再对着黑窗口敲命令。

它把「选脚本、配环境、填参数、点运行」这四步收进一个界面：脚本按项目归档摆放，虚拟环境自动匹配，运行结果实时显示，常用脚本还能置顶收藏。你不需要记住命令，也不需要背参数，更不用盯着控制台猜它到底跑没跑成。

最新更新（v4.1.0）：激活窗口全新改版，五个页签按使用场景重排、登录状态改为醒目账号条；发送验证码前先校验邮箱是否绑定，并修复了申请码与报单身份漂移的问题。

二、核心特色

🤔 你可能遇到这些问题
  • 记不住「先激活环境、再切目录、最后 python xxx.py」这一长串命令？
  • 装错了包、版本冲突、动不动提示找不到模块，却不知道脚本到底跑在哪个环境里？
  • 脚本一多就乱，文件散落在各个项目目录，今天跑这个、明天跑那个全靠翻？
  • 脚本是成功还是报错、跑了多久，只能守着黑窗口看？
  • 手里只有别人写好的 .bat 批处理，也想一键运行、看输出？
  • 换电脑、重装系统后，脚本列表和参数还得重新配一遍？
✅ KanlorOne RunVenv 的核心优势
  • 一键运行：选中脚本、填上参数（多数可留空），点一下「运行」即可，结果直接显示在窗口里
  • 环境自动匹配：自动识别当前脚本适合用哪个 Python 环境，减少装错包、版本冲突
  • 脚本可管可搜：列表 / 缩略图双视图，实时搜索，按项目归档，多项目一键切换
  • 置顶收藏 + 最近运行：常用脚本一键置顶（恒排最前），也可按最近运行时间排序
  • 运行状态可视化：运行中 / 成功 / 失败徽标与执行耗时直接标在列表和缩略图上
  • 批量整理：多选后一次完成批量改分组、批量移除、批量更换图标
  • Python 与 bat 双支持：.py 与 .bat/.cmd 一视同仁，编码自适配，中文不乱码
  • 出错可补救：缺模块会给出提示，并提供一键安装入口
  • 数据存本机：脚本列表、参数、环境设置都保存在本机用户目录，卸载升级不丢，配置还有自动备份

三、使用指南（8 步上手）

1
打开软件：解压下载的压缩包，双击 KanlorOne_RunVenv.exe 即可启动，无需安装。
2
添加脚本：点右上角「＋ 浏览添加」选择 .py / .bat / .cmd 文件；也可以在脚本区空白处双击快速添加。添加时会自动把脚本所在目录记入最近项目。
3
选脚本、配环境：在左侧选中要运行的脚本，右侧「虚拟环境（Python 解释器）」会自动匹配或由你手动下拉选择；若检测到缺少第三方模块，可直接一键安装。
4
填参数（可选）：在「参数」框里填写脚本需要的命令行参数，大多数脚本留空即可。日志区工具栏上的「保存」可把当前脚本与参数一并记住。
5
运行：点「▶ 运行 (F5)」开始，输出会实时显示在下方「输出日志」区；需要中止时点「■ 停止 (Esc)」。
6
看结果、导出日志：日志区支持清空日志、复制内容、导出日志；运行状态（运行中 / 成功 / 失败）与耗时会显示在脚本卡片或列表行上。
7
整理脚本（可选）：用「置顶收藏」把常用脚本排到最前；用分组页签归类脚本（可拖拽切组）；多选后可批量改分组 / 移除 / 换图标；左上角「当前项目」下拉可一键切换项目目录。
8
按需注册：未注册用户可先在注册 / 关于窗口点「开始试用」，试用期内全部功能解锁；日常「选脚本、跑脚本、看结果」的完整流程免费可用。
小提示：脚本区空白处双击就能添加脚本；未选中脚本时点运行，软件会提示你先选一个，不会误跑。

四、功能详解

下面按模块介绍，免费标记的为免费版即可使用，注册标记的需注册后使用。

1. 脚本管理 免费

  • 双视图浏览：列表视图看信息、缩略图视图看得更直观，一键切换。
  • 实时搜索：输入关键字即时筛出目标脚本，脚本多了也不难找。
  • 双击运行：双击列表行或卡片即可运行；双击空白处则快速添加脚本。
  • 置顶收藏：给常用脚本打上 ★，恒排最前，不会被其他排序打乱。
  • 最近运行：记录每个脚本最近一次运行时间，可按此排序。
  • 运行状态徽标：列表与缩略图直接显示运行中 / 成功 / 失败与执行耗时。
  • 从列表移除：只移除列表记录，不会删除磁盘上的脚本文件。

3. 自定义图标 注册

  • 支持导入 PNG / JPG / BMP / ICO / GIF 作为脚本图标（方形、清晰即可），导入后永久保存在本机、与内置图标混池使用。
  • 视图模式卡片可右键「更换图标…」，弹窗内点击即应用，当前图标以蓝色边框标记，还支持「随机换一个」。
  • 图标按脚本分配，同类脚本不再统一显示同一张图，一眼就能分辨。

4. 虚拟环境管理 注册

  • 环境自动匹配：识别当前脚本适合哪个 Python 环境，降低装错包、版本冲突的概率。
  • 管理Venv：可设置扫描路径，汇总列出该路径下的所有虚拟环境，与已保存列表合并去重展示。
  • 环境信息：显示每个环境的 Python 版本与来源，可「设为当前脚本环境」「打开目录」「从列表移除」，也可删除不再需要的环境目录（有二次确认）。
  • 构建新环境：基于系统 Python 一键创建新的虚拟环境。

5. 模块管理 注册

  • 对指定虚拟环境查看模块列表、安装模块、卸载模块，执行结果直接输出到主界面日志区。
  • 安装时支持一次填多个模块、可带版本号（如 requests==2.31.0）。
  • 脚本运行报「缺少模块」时，软件会给出提示并提供便捷安装入口。

6. 新建临时脚本 注册

  • 不用离开软件，直接新建一个临时脚本来试跑想法，支持「Python 脚本」与「批处理」两种类型，后缀与代码区标签联动。
  • 批处理类型会自动预填命令模板，按中文系统习惯的编码与换行写出，避免中文乱码。

7. 运行与日志 免费

  • 实时输出：脚本运行时输出实时滚动显示，Python 与批处理体验一致。
  • 随时停止：点「■ 停止 (Esc)」即可中止；Windows 下会连同子进程一并结束，不残留。
  • 日志工具：清空日志 / 复制 / 导出日志，方便留存或贴给他人排查。
  • 编码自适配：Python 脚本按 UTF-8 输出，批处理按中文系统编码正确显示，中文不乱码。

8. 数据与本机保存 免费

  • 脚本列表、参数、环境设置、图标与分组等配置，全部保存在本机用户目录，卸载、升级都不会丢失。
  • 配置保存采用自动备份，配置文件损坏或丢失时可自动恢复。

五、下载安装

⬇ 下载 KanlorOne RunVenv

解压即用，无需安装。下载后把压缩包解压到任意目录（不建议放在系统盘根目录或带特殊字符的路径），双击其中的 KanlorOne_RunVenv.exe 即可启动，不会向系统写入安装信息。

运行环境

  • 操作系统：Windows（64 位）。
  • 是否联网：日常添加脚本、配置环境、运行脚本都不需要联网；仅在线激活、拉取授权、检查更新时需要联网，离线激活通道全程不需要联网。
  • 是否要装 Python：软件本身已内置运行环境，解压即可开箱使用；要运行的 Python 脚本本身仍需要本机有 Python 或对应的虚拟环境。
  • 是否要会命令：不需要，界面操作即可完成选脚本、运行、看结果。

安装与升级提示

  • 软件是绿色便携式，卸载＝删除整个文件夹；脚本列表、参数、环境设置保存在本机用户目录，删除程序文件夹不会丢。
  • 升级时解压新版本并覆盖即可，已保存的脚本列表、分组、图标、收藏与运行历史都会自动跟随恢复。
  • 强烈建议只从上方官方渠道下载，避免使用来源不明的安装包。
首次打开提示：如果系统提示「Windows 已保护你的电脑」，请点击「更多信息」→「仍要运行」。这是新版本程序首次运行时常见的系统提示，不代表文件有问题。

七、常见问题

问：需要安装吗？
答：不需要。软件是绿色便携式，下载后解压，双击 KanlorOne_RunVenv.exe 就能用，卸载直接删除整个文件夹即可。

问：需要联网才能用吗？
答：日常使用不需要。添加脚本、配置环境、运行脚本、看日志全部可以离线完成；只有在线激活、拉取授权、检查更新这类操作需要联网，离线激活通道全程不需要联网。

问：我不会 Python，能用吗？
答：能。你只要把别人写好的脚本添加进来，选好脚本点「运行」就行。软件会自动帮你匹配运行环境，缺组件时也会给出提示和一键安装入口。

问：试用是怎么算的？
答：未注册也可以先完整体验全部专业功能，也就是全功能试用；试用按设备计算，重装、换路径都不会重新获得试用期。试用期内标题栏会实时显示剩余天数，到期后自动回落为免费版，已保存的数据不会丢失，随时注册即可继续使用。

问：换电脑或重装系统后还能用吗？
答：单机注册绑定本机，不支持换机，重新办理即可；两台在线授权的用户在新电脑上登录同一账号、解绑旧设备并拉取授权后即可恢复使用。此外，脚本列表、参数、分组、图标等配置保存在本机用户目录，重装软件不会丢失。

问：软件支持哪些类型的脚本？
答：支持 Python 脚本（.py）与批处理脚本（.bat / .cmd）。两者都可以添加、运行、实时看输出、停止、导出日志；批处理还可以绑定虚拟环境，让脚本内部调用的 python 自动命中该环境。

问：运行时提示缺少模块怎么办？
答：软件会识别出缺少的模块并给出提示，提供便捷的安装入口；你也可以在「模块管理」里手动安装、查看或卸载第三方包。

问：怎么注册和购买？价格在哪里看？
答：在主窗口右上角点「注册」（开始试用或注册完成后显示为「关于」）打开窗口，按页签对应自己的场景办理即可。产品价格统一在官网公布，请以官网当期信息为准；具体办理步骤见《注册方法》文档，各档位权益见《权益说明》。
