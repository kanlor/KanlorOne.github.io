KanlorOne MDLens — Markdown 轻量阅读与编辑助手

一、产品简介

KanlorOne MDLens 是一款侧重阅读的 Markdown 轻量超级助手，用 Tauri v2 打造的阅读器与简单编辑器。双击任意 .md 文件即可瞬间开启、漂亮渲染——内建可导航的章节大纲、代码语法高亮、Mermaid 图表、KaTeX 公式、可即时预览的实时编辑，以及多种一键导出。

它完全离线、全部本地化：没有云端、没有遥测，数据与文件都在你的本机，隐私安全有保障。

最新更新（v1.8.6）：更新弹窗支持一键装完，并在下载中显示真实进度与「已下 / 总大小」；更新说明与安装包路径分区展示，同一会话内已下载过的版本再次打开直接进入安装。

二、核心特色

✅ KanlorOne MDLens 的核心优势
  • 三种显示模式：阅读 / 实时（所见即所得）/ 源码，循环切换，以顶部内容为锚点精准对应、不跳转
  • 完整 GFM 渲染：表格、任务清单、删除线、脚注、==高亮==、代码语法高亮（highlight.js）
  • 公式与图表：KaTeX 公式（离线可用），Mermaid 图表按需加载（仅含 mermaid 区块才加载）
  • 表格实时编辑：整行整列悬停高亮、增删行列、合并拆分、上移下移、边界插入
  • 一键导出：HTML / Word(DOCX) / PDF 免费导出；渲染后 HTML 经 DOMPurify 清理 + 严格 CSP，打开不可信文件不执行恶意脚本

三、使用指南

1
打开文件：双击任意 .md / .markdown / .txt 文件，或按 Ctrl+O，或从启动页「打开文件 / 打开目录 / 新建文档」进入。
2
选择模式：工具栏「阅读 / 实时 / 源码」循环切换（Ctrl+E）。阅读模式只读浏览；实时模式所见即所得编辑，预览随输入即时更新；源码模式直接编辑 Markdown 源码并支持矩形块选。
3
大纲导航：左侧章节大纲（TOC）根据标题自动建立，点击即可跳转并高亮当前章节，Ctrl+\ 可折叠。
4
编辑内容：实时模式下按 Ctrl+S 存回磁盘；用 Ctrl+Z / Ctrl+Y 撤销 / 恢复；Ctrl+F 查找替换。
5
导出结果：工具栏选择导出 HTML / Word / PDF（免费），长图 PNG 与图片 / 表格 / 代码 / 链接附件需注册。
推荐流程：双击打开 → 阅读模式浏览大纲 → Ctrl+E 进实时编辑 → Ctrl+S 存盘 → 导出目标格式。

四、功能详解

1 三种显示模式

阅读 / 实时（所见即所得）/ 源码三种模式，循环切换；切换时以切换前顶部内容为锚点，精准对应、不跳转。

2 GFM 渲染与脚注

支持表格、任务清单、删除线，[^1] 脚注正确渲染上标引用与底部定义区，双向点击跳转并高亮；==高亮== 渲染为黄色荧光标记，明暗主题自动适配。

3 公式与图表

基于 KaTeX（离线可用），支持行内公式与块级公式；Mermaid 图表按需加载，仅当文件含 mermaid 区块时才加载，导出同步保留。

4 表格实时编辑

阅读 / 实时模式下整行整列悬停高亮、增删行列、上移下移、左右移动、合并拆分；角落聚合菜单手柄与四边带方向箭头的边界插入条，吸附网格线一键插入行 / 列。

5 章节大纲与文件浏览器

大纲 / TOC 侧栏根据标题自动建立、滚动时高亮当前章节（Ctrl+\ 折叠）；文件浏览器（Ctrl+B）支持目录浏览、路径栏跳转、「仅MD/TXT」筛选、最近打开（可清空）、切换目录。

6 多标签页与撤销恢复

同时打开多个文档、标签管理与切换；撤销 / 恢复最多 10 步向前与向后，覆盖所有编辑入口。

7 源码模式矩形块选（列块选）

按住 Alt 拖拽在源码中选择任意 1~N 列矩形区域，按逐字符像素精确识别与高亮选中字符（CJK 汉字、制表符不错位），支持复制 / 剪切 / 删除 / 输入替换 / 粘贴，均可撤销。

8 语义内容上色 注册

对白、数字、英文、自定义词库分类着色，可一键开关；仅作用于显示层，绝不修改 Markdown 源码。大文件仅对自定义词库着色以保性能。

9 自动化工具 注册

标题自动编号、标题级别上升 / 下降（每次 1 级）、序列强调加粗、删除空行内容；作用于工作缓冲区，不直接写盘。

10 查找替换与多编码兼容

Ctrl+F 文档内查找 / 替换，全部匹配高亮 + 当前项强调、N/M 计数、单个 / 全部替换；自动识别 UTF-8 / GBK / Big5 / Shift_JIS / EUC-KR 等编码；本机相对路径图片与 Windows 盘符绝对路径图片均正确显示。

五、下载安装

系统要求
  • 操作系统：Windows 10 / 11（64 位）
  • 运行环境：基于 Tauri 构建，使用系统内建 WebView（WebView2）
  • 磁盘空间：至少 50 MB 可用空间
安装步骤
1
点击下方「下载 Windows 64位」按钮获取安装包。
2
运行安装程序，安装版会自动注册 .md / .markdown / .txt 文件关联（双击即可打开）。
3
启动软件，双击任意的 .md 文件即可快速阅读与编辑。
安全提示：本软件为开源作品，exe 尚未经过代码签名，Windows Defender 或 SmartScreen 偶尔会误报为「潜在不需要的程序（PUA）」。这是误报而非恶意程序，推荐优先下载安装版，误报几率通常更低。

八、常见问题

Q：需要联网才能使用吗？
A：完全不需要。MDLens 全部离线运行，无云端、无遥测，文件与数据都在本机。
Q：杀毒软件误报怎么办？
A：本软件为开源作品，exe 未经过代码签名，Windows Defender 或 SmartScreen 偶尔会将其误判为「潜在不需要的程序」。可在通知中按「允许 / 还原」，或到「Windows 安全中心 → 病毒与威胁防护 → 保护历史记录」还原。推荐优先使用安装版，误报几率更低。
Q：双击 .md 文件没有直接打开？
A：请使用「安装版」安装，它会自动注册 .md / .markdown / .txt 文件关联；若为绿色版，请先手动打开文件或右键「打开方式」选择本程序。
Q：哪些功能需要注册？
A：HTML / PDF / DOCX 导出免费。内容上色、自动化工具、长图 PNG、图片 / 表格 / 代码 / 链接附件导出需注册。
Q：支持哪些编码和图片路径？
A：自动识别 UTF-8 / GBK / Big5 / Shift_JIS / EUC-KR 等编码；支持 ![](images/x.png) 相对路径和 Windows 盘符绝对路径图片，均正确显示。
Q：能不能打开代码文件？
A：在「设置 → 文件支持」开启后，可直接以语法高亮代码块只读打开 .py/.js/.ts/.java/.c/.cpp/.go/.rs/.sql/.json/.yaml/.html/.css/.sh 等文件，源文件不被修改。
