KanlorOne ExcelKitPlus — 格智：Excel 效率增强插件

一、产品简介

KanlorOne ExcelKitPlus（中文名：格智）是一款 原生运行在 Microsoft Excel 里的办公效率增强插件。安装后，Excel 顶部的功能区会多出一个 ExcelKitPlus 页签——选中要处理的表格区域，点一下对应按钮，重复的整理、清洗、排版和搬运工作就完成了。

插件内置六大功能组：结构调整、样式设置、数据处理、文档操作、AI 工具、系统管理，覆盖日常表格工作中最常见的那几类麻烦事。除了开箱即用的内置功能，它还带官方功能包，并且支持你自己编写 Python / VBA / 流程 三类自定义功能，把常用的宏和脚本也搬进功能区，一处点击就能跑。

它不需要你安装 Python，不需要管理员权限，除「公式助手」需要联网调用大模型外，其余功能全部在本机离线运行，数据不出本机。程序文件与用户数据分开存放，升级、重装都不会覆盖你自己写的功能。

最新更新（V1.4.1）：页签加载自愈补强（偶发不显示时自动恢复），并加入后台预热，首次点击功能按钮不再等待冷启动。

三、使用指南

ExcelKitPlus 是一个 Excel 加载项，不能双击即用，需要先运行一次安装器把功能区注册到 Excel 中。整个过程大约 1~2 分钟。

1
下载安装包：从本页下载按钮或微云链接获取 KanlorOne_ExcelKitPlus V1.4.1.zip。
2
解压：把 zip 解压到任意目录（建议不要放在 Program Files），确认目录里有 ExcelKitPlus-Setup.exe。
3
关闭 Excel：请关闭所有 Excel 窗口，避免安装期间文件被占用。
4
运行安装器：双击 ExcelKitPlus-Setup.exe，等待进度条走完（共 6 步，约 1~2 分钟）。出现 INSTALL_OK DEPLOY_SUCCESS 提示即安装成功。
5
重新打开 Excel：在「开始」页签右侧看到 ExcelKitPlus 功能区页签，即安装完成。
6
开始使用：打开任意工作簿，选中要处理的数据区域，点击对应功能按钮即可。按钮悬停会显示该功能的说明。
安装前建议先放开 VBA 宏：安装过程需要在 Excel 里构建一个 VBA 桥（提供时间戳等辅助宏）。请按 文件 → 选项 → 信任中心 → 信任中心设置 → 宏设置，勾选「启用 VBA 宏」与「信任对 VBA 工程对象模型的访问」。若没有放开，安装时会提示「未生成 VBA 桥 xlam，VBA 辅助宏不可用」，插件主体功能不受影响。安装完成后，你可以按需把宏设置改回更严格的级别。
首次使用提示：第一次打开「功能管理」时，插件会先检查你的 VBA 运行环境，如果还没就绪，会弹出一次图文指引告诉你要勾选哪些设置，勾选「不再提示」后就不再打扰。

解锁 Pro 功能：打开插件页签的「注册」按钮，有两种方式——

  • 在线激活（推荐）：切到「在线激活」页，填邮箱 → 获取验证码 → 登录，自动完成本机激活，不用复制粘贴任何代码，功能区当场刷新，无需重启 Excel。
  • 离线申请：切到「离线申请」页复制申请码，联系客服完成授权后把授权码粘贴回来即可。断网、内网机器照旧可用。

四、功能详解

下面按用途分类介绍。免费 标记的功能未注册时也能直接用，注册 标记的功能需要注册后解锁。

数据清理

免费 文本清洗

把从网页、系统导出的表格里那些看不见的垃圾清掉：零宽字符、装饰性符号、控制字符、多余空格、编号式换行、重复标点，一次处理干净，肉眼看不出的脏数据不再干扰后续筛选和统计。

免费 日期时间标准

把乱七八糟的日期写法统一成标准格式（仅日期 / 仅时间 / 日期+时间三种输出模式），结果追加到新列，原列保留。识别不了的单元格自动标黄，方便你回头人工核对。

注册 删除表格空行

一键删掉选区里的空白行，让表头与数据重新连成一片，排序、筛选、透视都不再被断层行打断。

注册 删除文字空行

清理「看着有内容、其实只有空格」，或单元格内堆了很多空行的单元格，把文字行的空白压缩掉，表格更紧凑。

注册 删除形状图片

批量删除表格上叠着的文本框、普通形状和图片，可分别勾选要删的类型，并支持应用到全部工作表——数据下发前做一次「净身」很省事。

注册 自动填充

把选中列里的空白单元格按规则补上：智能填充、复制填充、序列填充三种模式，适合处理「只在首行写一次」的台账类表格。

数值与格式

免费 全局格式化

一次性统一字体、字号、边框、奇偶行交替上色、标题加粗居中，并自动适配列宽行高。可以只处理当前表，也可以应用到全部工作表。

免费 统调行高

把整表行高统一设为固定值，或在原行高基础上统一增减。几十页表格一次拉齐，打印和截图都好看。

免费 冻结表头

智能识别标题行并自动冻结，长表格往下滚动时表头始终可见；支持只处理当前表或应用到全部工作表，还能指定冻结到第几列。

免费 条件行填色

以所选列为条件分组，相同值恒用同一种颜色，整行循环着色，多列选区按整行组合分组。内置经典 13 色、冷色系、暖色系三套色板，人工核对时一眼就能看出分组边界。

免费 高亮重复异常

两种模式随心切换：重复值按 13 色循环标出同一值的所有出现位置；异常/空值用浅红色把空缺和可疑数据挑出来。数据体检的常用第一步。

免费 超链接设置

一键删除表内全部超链接（常用来清掉从系统导出时带上的蓝色下划线），或反过来批量给单元格设置统一的超链接格式：字号、字体颜色、背景颜色。

注册 数字文本转换

文本 ↔ 数字双向转换。解决「看起来是数字，其实存成了文本」导致求和为零、排序错乱这类经典问题。

注册 数据列归一化

对数值列做 Min-Max 归一化，把数据压缩到 0~1 区间并写入首个空白列，原列不动。做对比、打分、权重计算时很实用。

注册 WBS 格式化

面向项目 / 任务台账：可配置 WBS、任务、状态三类字段的映射关系，按层级自动缩进任务名、父级任务加粗、状态列按状态着色，一份原始任务表几秒变成规整的层级清单。

注册 文本序列强调

针对「一行里塞了多条内容」的单元格：把多行文本按行序列化，可选用数字序号或固定符号，并自动把冒号前的文字加粗，报价单、需求点的可读性明显提升。

统计与分析

免费 区域数据统计

选中区域即出结果：样本数、总和、最大值、最小值、平均值、中位数、标准差、Q1 / Q3。结果可以弹窗显示完整统计、生成一张统计摘要表，或只在状态栏给一句简短结论。

免费 高亮重复异常（辅助核对）

在执行清洗、拆分、合并这类写操作之前，先用重复值与异常/空值高亮做一次快速体检，确认选区里没有脏数据再动手，能省下大量返工时间。

注册 公式助手（AI）

不会写公式时的救兵：用一句话说明你的需求，公式助手结合当前选区的数据结构给出可用的 Excel 公式并直接插入单元格，也可以选择「解释并给公式」模式，顺带看懂这条公式在做什么。

需联网：这是插件中唯一需要联网的功能，其余功能全部离线运行。

批量处理

注册 按首列展开

按首列分组，把单元格内换行堆叠的多条内容拆成多条独立记录，输出到一张新表。适合把「一行多条」的汇总表摊平成明细表，原始数据不受影响。

注册 按首列整合

与「按首列展开」互为逆操作：把首列值相同的多行合并成一行，内容以换行形式归拢，输出到新表。明细表要变成汇总表时用它。

注册 拆分合并单元格

拆掉选区内所有合并单元格，并把原来的值填回每一个拆分出来的单元格，避免出现大片空白导致筛选、排序失效。

注册 按列合并单元格

把单列选区中连续相同的值合并成一个单元格，用于整理分类列、部门列等重复值密集的列，表格一眼看上去更清爽。

注册 生成导航页

在最前面建（或复用）一张「导航」表，列出所有工作表的名称、行数、列数，并自动加上可点击的超链接；还能附加返回链接及其所在单元格，多表工作簿来回跳转不用再翻页签。

注册 表格拆分文件

按指定列的键值，把当前工作表拆成多个独立的 xlsx 文件，可指定输出目录与数据起始行。分公司、分部门下发表格时最省时间的一步。

免费 文件合并表格

把整个文件夹里所有 xlsx 汇总成一个工作簿。弹出参数窗选择文件夹，并设置表头处理方式与数据起始行，几十份文件一次搞定。

注册 区域导出文件

把选中的连续区域单独导出成一个 xlsx 文件，可自定义文件名与保存目录。要单独发一段数据给别人时，不用另存为再手工删行删列。

自定义功能包

ExcelKitPlus 不只是一个工具箱，还是一个可以继续长大的功能平台。除了随插件发布的功能，你还可以加载官方功能包，或者自己写功能加进功能区。

免费 官方功能包（随插件自动载入）

插件启动时自动扫描并载入官方功能包，内含 6 个现成功能：文件合并表格、文本序列强调、流程示例、转置选区、插入测试数据、设置列宽。官方功能默认不占用功能区，可在功能管理中按需开启。

可编辑、不可删除：官方功能可以直接修改并保存，你的改动单独存放、升级不覆盖；不需要时可在功能管理中隐藏。改错了还能一键「恢复到官方版本」。

注册 新建 Python 功能

在功能管理器里直接编写 Python 脚本，按统一入口写法提供 run(xl, params=None) 函数即可。脚本运行在插件自带的运行环境里，可用标准库直接读写当前 Excel 选区、工作表与格式，写好后立刻在功能区多出一个按钮。点「智能识别」还能自动回填名称、说明、提示与图标。

注册 新建 VBA 功能

把你原来的 VBA 宏接进功能区：粘贴宏代码，点「从代码获取」自动解析出宏名并回填，不必再记住宏名、跑到「开发工具 → 宏」里翻找执行。

注册 新建流程（组合）功能

把多个现成功能按顺序串成一条流水线：全局格式化 → 高亮重复 → 区域统计，一步一键全跑完。每一步可以设置间隔延迟，单步失败不会中断整条流程，出错信息会记录下来。流程不写脚本，只做编排，内置、Python、VBA、其他流程都能作为其中一步。

免费 功能管理：一处管好所有按钮
  • 分类筛选：全部功能按「内置 / VBA / Python / 流程」四类，以及「显示 / 隐藏」两态筛选，找功能不用翻菜单
  • 一键执行：在管理器里就能直接试跑功能，Python 直跑当前代码，VBA / 流程保存后运行
  • 分组与布局：自由分组、排序、显示或隐藏（含内置功能），布局方案可保存多套并一键切换
  • 备份与迁移：单个功能导出、整包导出 / 导入、时间戳备份与恢复，换电脑也能把自定义功能带走
  • 官方功能还原：单功能「恢复到官方版本」，或整体恢复到官方功能版
  • 帮助入口：VBA 环境一键检测、打开图文说明、注册与关于，都收在「帮助」菜单里
自定义功能有上限吗？ 免费用户可持有的自定义功能合计上限为 6 个（官方 6 项已计入）。超过上限的功能会被自动隐藏，代码不删除、不丢失，注册后自动恢复显示。

七、常见问题

问：安装后没有看到 ExcelKitPlus 页签？
答：请依次确认——① 是否用的是 64 位 Excel；② 安装后是否重新打开了 Excel；③ 是否打开或新建了具体工作簿（停留在 Excel 开始引导屏时功能区整体不显示）；④ 「文件 → 选项 → 加载项 → 转到」中 KanlorOne ExcelKitPlus 是否处于勾选状态。若仍然没有，可关闭 Excel 后重新运行一次安装器（安装会自动清理功能区缓存）。

问：32 位 Excel 能用吗？
答：不支持，插件仅支持 64 位 Excel。查看方式：Excel → 文件 → 账户 → 关于 Excel，确认标注为 "64-bit"。

问：为什么有些按钮是灰的、点不动？
答：灰色按钮是需要注册后解锁的 Pro 功能。未注册也能正常使用全部免费功能；在插件页签点「注册」完成激活后，Pro 按钮会立即变为可用，并且不需要重启 Excel。

问：需要提前安装 Python 或者联网吗？
答：都不需要。插件自带运行环境，无需安装 Python，也无需管理员权限。除「公式助手」需要联网调用大模型外，其余功能全部在本机离线运行，表格数据不会上传。

问：换了新电脑，授权还能继续用吗？
答：一个账号在每个产品下最多可绑定 2 台电脑，可在注册窗「设备管理」中查看已绑定设备，并解绑不再使用的电脑以释放名额（新绑定的设备需满 7 天才能自助解绑）。若你使用的是离线申请方式，一份授权码只在一台电脑上生效，换机请重新申请并联系客服办理迁移。

问：未注册时为什么新增不了自定义功能？
答：免费用户可持有的自定义功能合计上限为 6 个（官方 6 项已计入）。超出上限的功能会被自动隐藏，代码不会被删除，注册后会自动恢复显示。

问：功能执行后能撤销吗？
答：不能。插件的功能是直接修改 / 覆盖当前工作表数据的一次性写操作，没有 Ctrl+Z。请在正式数据上执行前先备份工作簿（另存一份副本），在副本或空白表上试跑确认结果符合预期，再对正式数据执行；自定义的 Python / VBA / 流程功能建议先通读代码再运行。

问：杀毒软件报毒或拦截安装怎么办？
答：插件的运行环境由打包工具生成，个别杀毒软件可能误报。把安装目录加入杀毒软件白名单即可；安装与运行都只写入当前用户，不需要管理员权限，也不会修改系统目录。
